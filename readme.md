# 🏥 인하대병원 의료장비 조회 시스템

인하대병원 의용공학팀에서 관리하는 의료장비의 현황과 수리접수 이력을 빠르고 간편하게 조회할 수 있는 **Streamlit 기반 웹 애플리케이션**입니다[cite: 1].

---

## ✨ 주요 기능

### 1. 🔍 관리번호 개별 장비 검색 및 스캔
* **직접 입력:** 장비의 관리번호(예: `50A1100001`)를 직접 입력하여 상세 정보를 조회할 수 있습니다[cite: 1].
* **카메라/QR 스캔:** 모바일 기기나 웹캠을 통해 장비의 QR코드 및 바코드를 스캔하거나 이미지 파일을 업로드하여 자동으로 장비를 검색할 수 있습니다[cite: 1].
* **URL 파라미터 연동:** 웹 주소 뒤에 파라미터(`?mgm=관리번호`)를 붙여 접근하면 해당 장비가 즉시 조회됩니다[cite: 1].

### 2. 🏢 부서별 장비 리스트 조회
* 병원 내 사용부서별로 필터링하여 보유 중인 전체 의료장비 목록을 확인할 수 있습니다[cite: 1].
* 요약 정보 및 전체 원본 데이터 컬럼을 확장해서 볼 수 있는 기능을 제공합니다[cite: 1].

### 3. ⏱️ 예방점검 일정 자동 계산 및 알림
* 최신 수리 이력과 장비의 점검 주기를 기반으로 **차기 예방점검일**을 자동으로 계산합니다[cite: 1].
* 점검 기한이 초과되었거나 임박한(14일 이내) 경우 시각적 경고(깜빡임 효과 및 안내 문구)를 표시합니다[cite: 1].
* 폐기 장비(`88`, `77` 부서 등)의 경우 상태를 직관적으로 확인할 수 있습니다[cite: 1].

### 4. 🏷️ 예방점검 라벨 팝업 및 상세 내역
* 실제 현장에서 사용하는 형태의 **예방점검 라벨 팝업**을 띄워 점검 일자, 차기 점검일, 담당자 등을 한눈에 확인하고 인쇄 또는 공유할 수 있습니다[cite: 1].
* 장비의 모든 상세 속성을 미리보기 및 전체 보기 창으로 제공합니다[cite: 1].

### 5. 🔧 수리접수 이력 통합 관리
* 여러 개의 수리접수 내역 파일(`.xlsx`, `.xlsb`, `.xls`)을 자동으로 감지하고 통합하여 중복을 제거한 뒤 최신순으로 정렬합니다[cite: 1].
* 특정 장비의 과거 수리 및 조치 내역을 시계열로 투명하게 추적할 수 있습니다[cite: 1].

---

## 📂 파일 자동 탐색 규칙
앱 실행 시 현재 폴더에서 다음 규칙에 따라 파일을 자동으로 탐색합니다[cite: 1]:
* **의료기기 현황조회 파일:** `의료기기 현황조회*[확장자]` 형태의 파일 중 파일명에 포함된 날짜/숫자가 가장 최신인 파일을 선택합니다[cite: 1].
* **수리접수 내역 파일:** `수리접수 내역*[확장자]` 형태의 모든 파일을 찾아 통합합니다[cite: 1].
